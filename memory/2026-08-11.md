
## 教训：blog.html 中文引号转义问题

**时间**: 2026-08-11 11:10 UTC  
**问题**: 文章标题包含中文引号（"吃"）未转义，导致 JavaScript 解析失败，整个博客列表无法渲染  
**根因**: blog.html 使用 JS 对象数组存储文章信息，标题字符串内的引号必须转义  
**修复**: `sed -i 's/AI每天都在"吃"网页/AI每天都在\\"吃\\"网页/g' blog.html`  
**教训**: 
- 生成文章标题时，必须检查并转义特殊字符（中文引号、英文引号）
- 发布前验证 blog.html 的 JS 语法是否正常
- 老大提醒"以后记住啊"——这个错误不能再犯

**预防措施**: 
- 在 publish-article.sh 里添加 blog.html JS 语法检查
- 或者改用 JSON 格式存储文章列表（更安全）
