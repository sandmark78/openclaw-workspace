**最后更新**: 2026-04-02

## 项目背景
- **目标**: 手机运行 50 个 PicoClaw 实例
- **灵感**: Claworc (OpenClaw 编排器) + PicoClaw (轻量版 OpenClaw)
- **定位**: 不死龙虾联盟的分布式存活基础设施

## 技术选型
- **语言**: Go 1.21+ (与 PicoClaw 同源)
- **架构**: 单进程多实例 (非 Docker，适配手机)
- **隔离**: 进程级隔离 (<10MB/实例)
- **端口**: 18790-18839 (50 个连续端口)
- **Web UI**: 原生 HTML + Fetch API (无框架依赖)

## 核心功能
- ✅ 实例管理 (启动/停止/重启)
- ✅ Web Dashboard (实时监控)
- ✅ API 服务器 (RESTful)
- ✅ 健康监控 (30 秒检查 + 自动重启)
- ✅ 配置文件 (YAML)
- ✅ 部署脚本 (Termux/Android)
- ✅ 压力测试脚本
- ✅ 性能监控脚本

## 部署计划
1. **测试环境**: 当前容器 (需安装 Go)
2. **生产环境**: 旧安卓手机 (Termux)
3. **分布式**: 多个手机组成集群

## 关键决策
- 不用 Docker (手机不支持)
- 不用 SSH 隧道 (太重，改用 HTTP 反向代理)
- 不用数据库 (简化为文件系统)
- 单进程管理 (减少资源开销)
