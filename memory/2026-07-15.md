## 11:15 UTC - 选题去重机制改进

**问题**：首页出现两篇关于"App vs 网页"的雷同文章，去重机制在写文章后才执行，浪费资源

**改进措施**：
1. **素材抓取阶段加入去重检查**
   - 更新所有 5 个素材抓取 Cron 任务
   - 在抓取素材前，先检查今日已发布的文章
   - 选择话题时，必须和已有文章不重复
   - 明确禁止抓取重复话题

2. **文章生成阶段保留去重检查**
   - 所有文章生成 Cron 任务已有去重检查
   - 写文章前执行 `check-topic-duplicate.py`
   - 如果发现重复，必须换话题

**去重流程**：
```
素材抓取 → 检查今日文章 → 选择不重复话题 → 保存素材
文章生成 → 读取素材 → 再次检查去重 → 写文章 → 发布
```

**效果**：在选题阶段就避免重复，不再写好了再去重
