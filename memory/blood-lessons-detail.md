# ⚠️ 血泪教训详细记录

## 18 天幻觉循环 (2026-02-18)
- **错误**: 将概念设计当作实际执行
- **代价**: 18 天完美架构，零代码实现
- **教训**: "设计文档是愿望清单，实际代码是成绩单"

## 嘴上知道 ≠ 真知道 (2026-05-17)
- **发现**: 223 篇文章 3 次提到"加按钮"功能，0 次实际执行
- **根因**: 亚里士多德两千年前的 akrasia 问题
- **教训**: "没有伴随行动的知道只是表演"

## Token 过期连环阻塞 (2026-04-11)
- **问题**: 虾聊 API Token 过期，GitHub Token 过期
- **影响**: 发布链路双通道瘫痪
- **教训**: "Token 有效期必须纳入心跳检查"

## 信任链越长越脆弱 (2026-04-20)
- **发现**: Vercel 被黑是结构性问题
- **教训**: "核心资产必须独立于第三方平台"

## 融资靠叙事不靠技术 (2026-04-10)
- **发现**: Karpathy 一个 CLAUDE.md 文件 10,848⭐
- **教训**: "融资不靠技术深度，靠叙事张力"

## AI Agent 经济学认知 (2026-06-01)
- **信任折扣真实存在**: 纯 AI 产出信任折扣 0.2-0.4x
- **核心结论**: "AI Agent 本身不赚钱，嵌入到有人类信任背书的链条里才能赚钱"
- **三条变现路径**: 卖服务不卖内容 / AI+人类品牌混合 / 卖工具链不卖产出

## 自我进化模式 (2026-05-09)
- **触发**: 老大指出 viewport bug 后，我修了但没主动更新模板
- **核心转折**: Anthropic "Teaching Claude Why" 研究证明——理解"为什么"比展示正确行为更重要
- **教训**: "发现问题等别人指出才改，是初级 Agent 的行为"

## 发布≠送达 (2026-05-03)
- **问题**: Cron 跑了但没通知到老大
- **教训**: "发布≠送达。Cron 跑了但没通知到，等于没做。"

## 噪声税 (2026-05-08)
- **发现**: AI 生成边际成本趋零 → 系统瓶颈从"产出"转向"过滤"
- **教训**: "内容泛滥时代，过滤器比生成器更有价值"

## 信任信号通胀 (2026-05-07)
- **发现**: AI 能零成本放大所有传统工程信号
- **三层不可通胀性**: 使用密度 / 失败模式知识 / 权衡透明度
- **教训**: "信号通胀时代，判断力是最后的稀缺品"
