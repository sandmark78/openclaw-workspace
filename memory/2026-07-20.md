## 改进：审计脚本添加修复功能

### 新增参数
```bash
python3 scripts/post-publish-audit.py --fix-blog    # 自动修复 blog.html 索引
python3 scripts/post-publish-audit.py --fix-rss     # 自动修复 RSS
python3 scripts/post-publish-audit.py --fix-all     # 自动修复所有问题
```

### 修复功能
- **--fix-blog**: 自动扫描所有文章，更新 blog.html 的 articles 数组
  - 提取标题、日期、标签、副标题
  - 按日期倒序排序
  - 保留最近 50 篇文章
  - 自动转义特殊字符
- **--fix-rss**: 调用 rss-auto-writer.sh 修复 RSS
- **--fix-all**: 执行所有修复

### 使用场景
1. 发现博客列表不显示文章 → 运行 `--fix-blog`
2. 发现 RSS 过期 → 运行 `--fix-rss`
3. 定期审计 → 运行 `--scan` 检查问题，然后 `--fix-all` 修复

## 核心教训

**审计 + 修复 = 完整工作流**

以前只有审计，发现问题后需要手动修复。现在审计脚本自带修复功能：
1. 运行 `--scan` 发现问题
2. 运行 `--fix-all` 自动修复
3. 验证修复结果

这样可以快速响应问题，减少人工干预。
