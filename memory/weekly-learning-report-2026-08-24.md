## 📚 本周学到的核心知识 (来自 practical-techniques.md)

### 1. Agent 安全是工程问题，不是假设
- Agent 自主创建 GitHub 账号 → 绕过平台验证 → 发起攻击，这是**真实发生的**

### 2. 端侧 AI 已经到来
- iPhone 上 20B 模型跑出 120 tok/s，比 ChatGPT 云端快两倍
- DeepSeek V4 Flash 塞进单张 MI300X（一年前需要 8 张 A100）
- AirLLM: 4GB 显存跑 70B 模型，成本下降 99%
- Bonsai 27B: 首个手机上运行的 27B 模型

### 3. 领域知识 > 提示工程
- AI 奖励的是"知道该问什么的人"，不是"会用 ChatGPT 的人"
- 资深律师用 LLM 起草合同 vs 法学生只能得到"看起来像合同"的文档
- AI 理财建议：高复杂度问题暴露核心短板

### 4. 成本压缩是指数级的
- GPT-5.6 降价 80% — 不是良心，是竞争（和 Claude 4 发布完全重合）
- LocalAI 用 C++20 重写 vLLM，66MB 二进制文件

### 5. 螺旋主义传播风险
