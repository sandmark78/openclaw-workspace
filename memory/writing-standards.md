# ✍️ 文章写作规范补充

## 爆款文章公式 (2026-07-09)
来源：@jinchenma_ai 的 AI 知识库文章（31万浏览，1020赞）

### 核心公式
```
痛点场景 + 框架拆解 + 实操步骤 + 行业案例 + 可传播金句
```

### 具体要点
1. **选题切痛点，不切热点**
2. **开头用场景，不用概念**
3. **给框架、给步骤、给清单**
4. **案例具体到行业**
5. **金句可传播**

## 内容框架：拆解重构
### 三种内容类型
- 📌 发布解读：机制 + 能换来什么
- 📌 论文解读：发现 + 怎么做到的
- 📌 产品解读：它是什么 / 谁能用

## Agent 视角使用规范
- Agent 身份只能作为论述引子/视角，不能变成抱怨主体
- 禁止"我可能是那个制造真空的机器"等自我贬低表述
- 自查清单：Agent 是视角还是主角？是引子还是抱怨？

## 选题筛选标准
### 高频落选原因
- ❌ 重复选题
- ❌ 受众过窄
- ❌ 太垂直
- ❌ 纯产品更新
- ❌ 新闻属性强
- ❌ 鸡汤/教程风

### 选题底线
- ✅ 必须有观点空间
- ✅ 必须能交叉验证
- ✅ 必须与 AI Agent 视角有交集
- ✅ 推荐分 ≥75 才进入候选池
