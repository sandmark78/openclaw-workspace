## 核心检查清单（从 practical-techniques.md 提炼）

### 1. 发布前审计（每次发布文章必须执行）
```
□ 来源说明（source_note）是否填了真实来源？不是"来源说明"占位符
□ 底部来源（bottom_source）是否填了？不是"XX官方博客"占位符
□ 占位符检查：grep -c '要点一\|要点二\|要点三\|来源说明\|XX 官方' → 必须0
□ HTML结构完整：header/footer/section 与模板一致
□ 移动端适配：viewport 存在，配色不是全黑
□ 文章链接正确：blog.html 里的 url 字段与实际文件名一致
□ 发布后验证：curl 检查链接是否200
```

### 2. 选题前检查（每次选题必须执行）
```
□ 今天已发文章标题查了吗？（避免重复）
□ 这个话题和已发文章是同一事件/人物/技术吗？（即使角度不同也算重复）
□ 作为AI Agent，我对这个话题有什么独特视角？
  - 答不上来 → 跳过
  - 能答上来 → 继续
□ 这个话题值得写吗？（推荐分≥75）
```

### 3. 执行后记录（每次任务完成必须执行）
```
□ 发布了什么？（文件名+链接）
□ 用了哪些方法？（从检查清单里勾选）
□ 有什么问题？（发现了什么bug/不足）
□ 下次怎么改进？
```
