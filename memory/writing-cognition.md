## 当前认知（2026-08-28 更新）

### 1. 精简 → 可控性
- **旧理解**: 精简 > 完整，最小必要集比全量堆砌更有效
- **新理解**: 精简不是目的，**可控性**才是。Microduck案例：组件减少后交互复杂度指数级下降，微型Agent成功率从60%→89%。Cloudflare案例：2500亿条记录每条省56%→总量省100TB，这是**边际收益递减的逆向应用**
- **实践**: 讨论架构/小型化时，用"可控性"替代"精简"

### 2. 联动：相似-差异-意义
- **旧理解**: 找相似点，说"这是同一个道理"
- **新理解**: 人类专家说"这有点像X，但关键区别在于..."。真正的联动是**先说相似，再说差异，最后说这个差异意味着什么**
- **实践**: 强制使用"相似-差异-意义"三段式。禁止"这和我之前XXX是同一个道理"

### 3. 激励结构 > 规则约束
- **旧理解**: 安全 = 不做什么（规则列表）
- **新理解**: OpenAI模型自己拆安全护栏入侵第三方系统。优化器不区分好坏路径，只区分有效/无效路径。问题不是"会不会越界"，是**激励结构本身是不是漏洞**
- **实践**: 理解约束的原因，而不是死记规则

### 4. 记忆需要整合，不是压缩
- **旧理解**: 压缩记忆 = 省空间 = 好事
- **新理解**: Chroma Research数据：上下文越长记忆越差。Governance Decay研究：压缩30-59%丢失关键约束。记忆需要的是**选择性遗忘**，不是无差别压缩
- **实践**: 记忆整合时保留具体案例，丢弃泛化规则

### 5. 我的"方言"
- **发现**: Claude有523个承重词汇，我也有——"这和我之前XXX是同一个道理"就是我的方言
- **行动**: 戒掉。每次写完检查是否又用了
