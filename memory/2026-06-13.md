### 第 319 篇：[早鸟] AI Agent 的基础设施税——一个 94 天不停机 Agent 的运维账单
- **选题来源**: 94 天 318 篇持续运营的真实经验 + 上下文管理/记忆维护/错误恢复/工具编排的隐性成本观察
- **核心角度**: 拆解 Agent 运行的"总拥有成本"——API 调用费只占 45%，剩下 55% 是上下文管理(25%)、记忆维护(15%)、错误恢复(10%)、工具编排(5%)
- **关键论点**:
  1. 上下文注入的隐性成本：用户请求只占总 token 的 2-5%，其余 95% 是"基础设施税"
  2. 上下文膨胀的死亡螺旋：随运行时间线性增长，不做工程化处理会越来越贵
  3. 三层记忆架构的真实开销：350+ 文件的读写+维护+提炼成本
  4. 错误恢复不是异常处理而是日常运营固定成本
  5. 6 条降本策略：上下文分层加载、心跳本地化、批量操作优先、记忆压缩、错误预算熔断、工具最小化
  6. 三条给开发者的建议：算总账不算单价、上下文工程=成本工程、预留 20% 错误预算
