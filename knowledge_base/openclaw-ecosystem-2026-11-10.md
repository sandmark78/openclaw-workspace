## 3. GitHub Releases - 2026.11.3 版本亮点

### 🆕 重要新功能

#### 私有任务结果 (#188490)
- 私有子 Agent 完成结果不再流入聊天回复
- 保护敏感任务输出

#### 可靠的子任务交接 (#178893)
- 父任务可以在取消子任务后交接给替代工作
- 取消的子任务完成凭证不再阻止交接

#### 可见的工具失败 (#182458)
- 未回答的工具失败会被报告，而不是静默结束
- 之前会假装成功的失败现在会正确报告

#### 有界认证 (#189144)
- 在运行截止时间停止停滞的提供商认证
- 通过认证工作传播取消

#### 沙盒图像访问 (#176203)
- 即使在完全访问模式下，也将沙盒图像预览限制在允许的文件夹内
- 保留显式管理员图像允许

#### 验证工作区连接 (#125646, #190002)
- 提供空指纹时保留保存的节点证书钉
- 在发送凭据或数据之前验证工作区传输证书

#### 更快、响应更快的 Gateway (#192217, #184433)
- 减少启动模块文件加载开销
- 避免中止命令检测遇到长标点符号运行时的停滞

### 🔧 重要修复

#### 凭据隔离 (#178444, #177974, #189423)
- 保持重用和缓存的插件结果范围在其连接凭据内
- 保持其他插件的传输钩子在提供商的源上

#### 搜索和记忆凭据 (#190706, #184966)
- Firecrawl 搜索和抓取键与其范围端点保持
- 嵌入凭据与其目的地保持

#### 凭据编辑 (#190618, #178745)
- 从配置读取中编辑内联环境凭据
- 从 Exa 错误中编辑反射的搜索凭据

#### 子进程环境 (#179198, #179415)
- 防止管理的 Signal 守护进程和捆绑语言服务器继承不相关的 Gateway 秘密

#### 认证错误 (#173970, #181597)
- 表面凭据读取失败而不是将其视为缺失凭据
- 拒绝属于不兼容提供商的显式选择的认证配置文件

#### 频道安全 (#174552, #186243)
- 保持传入的 Twitch IRC 内容远离解析器错误日志
- 当多个 Tlon 批准待处理时需要显式请求 ID

#### 计划任务 (#175678, #168985)
- 处理排队的 cron 存储失败而不退出 Gateway
- 当任务变为循环时清除一次性清理

#### 更新恢复 (#181906)
- 在初始包存在检查超时时安全恢复
- 在替换之前需要新的有效目录标识
- 保留回滚到原始包

#### Anthropic 使用上限 (#176186)
- 识别耗尽的复数使用限制错误而不花费瞬态速率限制重试预算

#### 终端会话 (#172431)
- 将 /reset soft 转发到 Gateway 而不是硬重置会话

#### Git 恢复 (#176006)
- 在 Git 修复期间保留不确定的命令失败
- 而不是将未确认的操作视为成功

#### 记忆提供商选择 (#186310)
- 接受混合大小写的 none 和 auto 提供商值
