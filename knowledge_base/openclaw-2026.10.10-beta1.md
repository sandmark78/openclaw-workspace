## 🚀 核心亮点

### 1. 性能优化：更快更稳定的 Gateway
- 聊天轮次、会话列表、启动和空闲 Gateway 大幅减少 SQLite 和主线程工作
- 更多数据库工作转移到工作线程
- 繁忙主机和大型代理集群保持响应
- 相关 PR: #167965, #168002, #168093, #169005, #169164, #171685, #170151, #169871, #168649, #170612, #171371, #171805, #168992, #169543

### 2. 更新可靠性改进
- 从 2026.10.1 及更早 beta 版本升级能正常完成
- 繁忙 Gateway 和慢速 Doctor 步骤不再拒绝或回滚有效更新
- 失败更新不再留下半安装版本
- macOS、Windows 和 Bun 安装从平台特定故障中恢复
- 相关 PR: #168849, #172249, #172196, #172151, #172247, #171101, #170519, #172640, #171936, #170940, #171077, #172494

### 3. 重启安全恢复
- 中断和未完成的回复在 Gateway 重启后恢复
- 监视的子进程结果、排队轮次、接受的代理更新和操作员任务在重启后保留
- 相关 PR: #172234, #172412, #169489, #171717, #170697, #170858, #170384, #172356, #172023

### 4. 云会话功能
- 从会话菜单在本地和云端之间移动会话
- 使用环境配方和经过验证的 Node 工具链按存储库组织云环境
- 在第一个快照完成上传之前查看快照进度
- 相关 PR: #171690, #170892, #170862 (及更多)
