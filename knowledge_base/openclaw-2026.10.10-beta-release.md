# OpenClaw 2026.10.10-beta.1 发布说明

**抓取时间**: 2026-10-15 20:00 UTC

**上一版本**: 2026.10.5-beta.4

## 🚀 核心亮点

### 1. Gateway 性能大幅提升
- **优化内容**: 聊天轮次、会话列表、启动和空闲 Gateway 的 SQLite 和主线程工作量大幅减少
- **技术细节**: 更多数据库工作移至工作线程
- **收益**: 繁忙主机和大型 Agent 集群保持响应
- **相关 PR**: #167965, #168002, #168093, #169005, #169164, #171685 等 14 个 PR

### 2. 更新可靠性提升
- **问题解决**: 
  - 从 2026.10.1 及更早版本升级能正常完成
  - 繁忙 Gateway 和慢速 Doctor 步骤不再拒绝或回滚有效更新
  - 失败更新不再留下半安装版本
  - macOS、Windows、Bun 安装恢复平台特定故障
- **相关 PR**: #168849, #172249, #172196, #172151 等 14 个 PR

### 3. 重启安全的回复
- **功能**: 中断和未完成的回复在 Gateway 重启后恢复
- **保留内容**: 
  - 监控的子 Agent 结果
  - 排队的轮次
  - 接受的 Agent 更新
  - 操作员任务
- **相关 PR**: #172234, #172412, #169489, #171717 等 9 个 PR

### 4. 云会话功能
- **核心能力**: 
  - 从会话菜单在本地和云之间移动会话
  - 按仓库组织云环境（环境配方 + 验证的 Node 工具链）
  - 会话启动时显示快照进度
- **相关 PR**: #171690, #170892, #170862, #170796 等 7 个 PR

### 5. 桌面应用本地 Gateway
- **Windows**: 桌面应用支持运行本地 Gateway
- **macOS**: 全新安装启动引导仪表板设置
- **首次运行**: 自动选择推理配置
- **相关 PR**: #169522, #169512, #169568, #169628

## ⚠️ 重要变更

### Apple 平台要求提升
- **最低版本**: macOS 26.2, iOS 26.2, Safari 26.2
- **影响**: 原生应用和 Control UI
- **PR**: #168595

### 实验性 PostgreSQL 支持
- **功能**: Workboard 存储的 PostgreSQL 引擎
- **特性**: 
  - 从规范 SQLite 模式生成 PostgreSQL DDL
  - 带能力承认的迁移
  - 精确的模式漂移检查
  - 备份和更新中保留 PostgreSQL 存储
- **相关 PR**: #169214, #171962, #168219 等 19 个 PR

### Bun 运行时支持
- **功能**: 使用 Bun 构建独立 OpenClaw 可执行文件
- **特性**: 
  - 可选的固定 Bun 运行时
  - 更快的 Gateway 启动
- **相关 PR**: #172384, #168832, #168982

## 🐛 重要修复

### Gateway 生命周期
- 回复标记流期间保持响应
- 长引用工具 XML 不再触发每令牌 Markdown 解析
- 睡眠和时钟变化后恢复状态所有权
- 停止阻塞的转录工作线程

### 更新和 Doctor
- macOS 主机上的 Doctor 完成后修复不再失败
- 慢速更新承认不再阻塞数据库写入器
- Docker 升级在旧 Linux 主机上停止重试循环

### 通道和工具
- MCP OAuth 登录完成无端口环回注册
- 每个飞书监控启动获得独立的绑定适配器注册
