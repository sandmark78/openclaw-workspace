### OpenClaw v2026.10.7 (最新稳定版 - 扩展稳定版/LTS)

**发布日期**: 2026年10月  
**性质**: Gateway-only 扩展稳定版 (LTS 等价物)  
**基础**: OpenClaw 2026年9月底 + 关键安全更新 + 可靠性/性能修复 + 新模型支持

### 核心亮点

#### 1. 会话恢复安全性 (Replay-safe session recovery)
- 中断的会话现在保留恢复来源和未完成的工具结果
- 停止的对话在接受下一条消息前清除终端恢复残留
- 被拒绝的 Claude CLI 草稿不会进入最终回复
- 大型子代理完成批次保持在请求者上下文内
- Codex 预览在上下文刷新后不再阻塞回复

#### 2. 更安全的更新激活和恢复
- 验证的激活在后续维护或账本错误后保持成功
- 中断的包更新安全恢复
- 激活后 Doctor 等待有边界
- 过期收据不能否决有效修复
- Windows 深度或 8.3 状态路径不再中止入门或迁移

#### 3. 数据库和工作器连续性
- 维护拒绝保留对等读取器和借用器
- 不兼容的保留代理数据库保持隔离
- 空转录删除跳过不必要的归档物化
- Bun 准入截止时间保持线程本地
- 工作器关闭在库存退休后完成

#### 4. 备份和状态持久性
- 快照保留支持的旧版 exec-approval 策略
- 中断的 R2 验证和恢复安全恢复
- 配置观察在截断写入期间保留最后已知良好的快照
- 失败的多文件补丁保留早期文件
- Memory Wiki 重新导入保留人工编写的笔记

#### 5. 操作者控制连续性
- 原生计算机控制在会话过期后恢复
- 后期附加的 GitHub 操作者可以发布 PR
- 同步节点输出不会重复为完成唤醒
- cron 公告保留 CLI 聊天
- 历史维护在有效负载之前读取身份

#### 6. 提供商和插件连续性
- 模型刷新、配置账户准备、GPT-5.6 工具回合
- OpenRouter 入门
- 增量插件加载
- 更快的外部 TypeScript 插件启动
- 保留当前状态而不是拒绝有效设置或丢弃提供商

### 新增模型支持
- **Gemini 4 Argon** (Google) - PR #171852

### Node.js 安全要求 (重要!)
- **要求**: Node >=24.22.1 <25 || >=26.12.1
- **原因**: 拒绝使用2026年10月 Node.js 安全发布中解决的受损证书密钥签名的 TLS 链
- Docker 镜像已搭载 Node 24.22.1
- 安装程序选择修补的运行时
- `openclaw update` 在旧 Node 上安装前拒绝并提供恢复指导

### 其他修复
- macOS 入门：允许新配置文件启动 Gateway 并完成自动设置
- Gateway 日志：防止删除或过期的临时日志目录在日期翻转时将 Gateway 卡在满 CPU
- Control UI 队列状态：在队列命令被消费后清除斜杠引导芯片
