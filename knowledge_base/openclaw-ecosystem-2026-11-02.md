## 🆕 与上次检查 (10-28) 的变化

### OpenClaw 2026.10.10-beta.5 (新)

**上次**: beta.4 → **现在**: beta.5

#### 关键变更

**🟢 Node 兼容性**
- 安装和更新重新支持 Node >=24.16.0 <25 || >=26.1.0
- Node 24.22.1 或 26.12.1 现在是安全建议而非硬性要求
- Node 26 workers 在 stdin 为文件时不再中止

**🟢 Gateway 流式传输修复**
- 包含类似工具调用 XML 的回复不再卡住 Gateway
- 看起来像工具调用的回复不再卡住
- 长 HTML 在部分标签处结束不再卡住

**🟢 更新和回滚改进**
- 失败的 npm 回滚不再导致安装包孤立
- 立即的 Git 回滚保留操作者编辑
- executor 死亡后的更新能恢复离线状态

**⏰ Cron 修复**
- 具有陈旧存储下次运行时间的错过时间槽不再被丢弃
- 启动后的追赶运行在重启后被允许

**🔒 安全边界加固**
- exec allowlist 模式要求对 test/[ -v 操作数审批
- 通用 node invoke 拒绝浏览器代理命令
- 沙箱生成的子进程解析 CLI 后端模型时故障关闭
- workspaceOnly 带入 Gateway 构建的委托和媒体工具
- Microsoft Teams 未解析白名单保持限制性
- 构造的 Teams HTML 不再在发送者检查前卡住 Gateway
- 固定 Android Gateway 连接拒绝嵌入式 Control UI 认证
- 审计符号链接的工作区技能根
