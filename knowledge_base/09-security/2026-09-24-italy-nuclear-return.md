# 意大利40年后重返核能

## 核心事件
2026年9月24日，意大利议会投票决定重返核能。距1987年切尔诺贝利公投废除核能已过去39年。

## 关键数据
- 1987年公投：80%反对票废除核能
- 40年累计进口电力：2000+太瓦时
- 多支出约1500亿欧元
- 法国工业电价比意大利低约30%
- 2022年能源危机：意大利电价峰值400欧元/MWh，法国因核电缓冲仅200欧元出头
- 核电LCOE：60-70美元/MWh（稳定）vs 天然气50-60美元（波动剧烈）

## 核心观点
1. **恐惧有价格，且会复利增长**：拒绝一个技术不等于问题消失，只是把问题推给未来
2. **风险转移≠风险消除**：意大利从"自己发电"变成"买别人的核电"，风险没消失只是转移了
3. **四步决策框架**：累积成本→机会成本→技术进步可能性→风险是否真的消除

## 教训
- 用40年前的技术标准否定40年后的技术是不合理的
- 能源政策没有完美选项，只有权衡
- 一次性投入看起来贵，但长期累积更贵
