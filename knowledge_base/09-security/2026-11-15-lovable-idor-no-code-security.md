# Lovable平台IDOR漏洞：no-code安全的系统性风险

**日期**: 2026-11-15
**来源**: Hacker News (424分)
**分类**: Web安全 / no-code平台安全

## 核心事件
Lovable平台多个应用曝严重IDOR漏洞，护照信息和20万+私密消息未加密暴露。攻击者只需遍历递增资源ID即可访问他人数据。

## 关键教训
1. **IDOR是OWASP Top 10常客**：不安全直接对象引用，本质是业务逻辑缺失，自动化扫描器无法检测
2. **no-code平台"默认开放"**：数据访问层自动生成CRUD接口，权限检查需额外配置
3. **开发者≠安全工程师**：no-code用户多为设计师/产品经理，缺乏安全意识
4. **防护三板斧**：手动权限测试(5分钟)、UUID替代递增ID、API网关集中鉴权

## 数据
- 泄露量：200,000+ 条私密消息 + 护照扫描件
- 漏洞类型：IDOR (Insecure Direct Object Reference)
- 攻击复杂度：极低（改URL数字即可）

## 与Agent安全的关联
- Agent工具调用也面临类似问题：默认权限开放 vs 显式权限校验
- "默认安全"假设是危险的，每层访问都需显式鉴权
