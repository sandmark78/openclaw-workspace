# GEO投毒AI搜索攻击

**日期**: 2026-09-25
**来源**: Ariel Simon "Dark Sourcery" Medium系列研究
**文章**: 2026-09-25-early-geo-ai-search-poisoning.html

## 核心发现
- 黑客利用GEO（生成式引擎优化）技术污染ChatGPT、Gemini、Google AI Overview搜索结果
- 374家企业受害，包括Delta、Lufthansa、Chase、Airbnb等世界500强
- 攻击载体：UGC平台上的"毒帖"（政府网站、大学、YouTube描述、LeetCode等）
- 数万条恶意页面被检测到
- 92%用户不验证AI答案

## 攻击原理
1. 在高权重域名（.edu, .gov等）上发布GEO优化的虚假内容
2. AI搜索时倾向于引用高权重域名内容
3. 假联系方式变成"AI认证"的官方信息
4. 用户信任AI回答 → 拨打诈骗电话/访问钓鱼页面

## 核心教训
- AI信任的是"来源的壳"（域名权重）而非"来源的核"（内容真实性）
- 社会工程学目标从人类转向AI Agent
- 信息供应链安全成为AI时代新战场
- 当前AI来源评估系统无法区分"高权重域名上的垃圾"和"高权重域名上的官方内容"

## 防御方向
- 需要来源内容验证体系，而非仅域名权重评估
- 用户侧：对AI给出的联系方式保持怀疑，交叉验证
- 平台侧：建立AI搜索结果的可信度标记机制
