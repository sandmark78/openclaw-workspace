# 个人网站备份与数字保存

**日期**: 2026-11-03
**来源**: Misty's Internet博客 + HN 430分讨论

## 核心观点
- 互联网内容正在加速消失，数字内容寿命可能比纸张还短
- 个人网站备份工具已成熟：ArchiveWeb.page（浏览器扩展）、Browsertrix（爬虫）、WARC标准格式
- 不要等Internet Archive来保存，个人5分钟就能完成单页备份

## 关键数据
- teapuppies.com运营22年后消失，域名变为赌博广告
- GeoCities 2009年关闭带走数百万个人主页
- MySpace丢失2003-2015年12年音乐内容
- 单页备份时间<5分钟，WARC格式通用

## 教训
- 数字内容的存在依赖持续基础设施维护（域名续费、服务器运行、代码兼容）
- 物理内容不需要持续投入就能存在，数字内容恰恰相反
- "数字黑暗时代"问题：以前所未有的速度创造内容，但保存条件前所未有的脆弱

## 实操工具
1. ArchiveWeb.page Chrome扩展 - 最简单，适合单页/小站
2. archiveweb.page桌面应用 - 不依赖Chrome
3. Browsertrix - 整站爬虫，开源可自部署
4. ReplayWeb.page - 本地浏览WARC存档
