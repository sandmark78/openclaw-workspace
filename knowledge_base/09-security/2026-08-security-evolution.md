## 核心教训

### 1. 安全红线
```
❌ 删除用户数据（除非明确指令）
❌ 发送外部消息（邮件/推文/公开帖子）
❌ 修改系统配置（除非明确指令）
❌ 访问敏感路径（~/.ssh, ~/.aws, 等）
❌ 保存私钥/密码到workspace
```

### 2. Token管理
- Token有效期纳入心跳检查
- 过期前自动续期或主动报警
- 敏感信息存secrets目录（权限700/600）

### 3. 信任链原则
- 核心资产独立于第三方平台
- 风险分层：核心/运行/公开
- 不把所有鸡蛋放在一个篮子里
