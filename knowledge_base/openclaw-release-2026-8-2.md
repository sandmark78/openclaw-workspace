## 🆕 重要新功能

### 1. Home Agent 侧边栏 (实验性)
- **快捷键**: Cmd/Ctrl+Shift+H
- **功能**: 在右侧或底部 dock 打开 Home agent
- **特性**: 
  - 保持当前页面可见
  - 预览/移除工作上下文快照
  - 附加选中文本到消息
- **相关 PR**: #133676

### 2. Linux 桌面伴侣应用 🐧
- **格式**: .deb 和 AppImage (x86-64)
- **功能**:
  - 连接本地或远程 Gateway
  - 从系统托盘打开 Quick Chat
  - X11 键盘快捷键支持
- **更新机制**: AppImage 签名验证，.deb 由包管理器管理
- **文档**: https://docs.openclaw.ai/platforms/linux

### 3. 后台会话创建
- **入口**: New Session 菜单
- **功能**: 创建并运行后台会话，不切换页面
- **特性**:
  - 选择本地/云端/配对设备放置
  - 从完成通知打开会话
- **相关 PR**: #128050

### 4. 更安全的升级机制
- **配置保护**: 保留更新的配置
- **迁移安全**: 不完整的会话迁移不会标记为成功
- **故障恢复**: 更新失败后可恢复停止的 Gateway
- **相关 Issues**: #118244, #90551, #134206
