# OpenClaw v2026.11.5 Release Notes

**发现时间**: 2026-11-17 20:00 UTC
**来源**: https://github.com/openclaw/openclaw/releases

---

## 核心亮点

### 1. 重启安全对话 (Restart-safe conversations)
- 排队消息、发送权限、最终聊天写入在 Gateway 重启后保留
- PR: #196923, #196540, #196493
- **影响**: 不再因重启丢失对话上下文

### 2. 更安全的更新 (Safer updates)
- Doctor 或 Gateway 启动失败时回滚已激活的更新
- 恢复的 npm 包保持非 root 服务可读
- PR: #197851, #193272

### 3. Telegram 交互组件 (Telegram widgets)
- 交互式组件现在可在 Telegram 消息中渲染（含私聊话题）
- PR: #196991, #198022
- **影响**: Telegram 用户体验提升

### 4. 更快的内存恢复 (Faster memory recovery)
- 大型内存索引重建可靠完成
- 嵌入索引在网关截断批量限制错误时恢复
- PR: #196378, #187797

### 5. 更可靠的模型回退 (More reliable model fallback)
- 配置的主账户不再阻止 Claude CLI 回退
- OpenAI 会话从压缩项冲突中恢复
- PR: #198427, #198357

### 6. 可用设备文件夹 (Usable device folders)
- 现有设备文件夹在默认运行时保持可选
- 每个文件夹选择有清晰的菜单行
- PR: #190065, #190088

### 7. 内容边界 (Content boundaries)
- 二进制附件不再变成乱码提示文本
- 认证的浏览器 CDP URL 不出现在工具结果中
- PR: #198309, #196262

---

## 其他变更

- **忙碌会话消息**: 个人模式消息引导兼容工作或静默排队，无需手动重发
- **安全预设**: 个人和企业安全预设提供一致默认值
- **压缩控制**: 可设置 maxSummaryChars 控制摘要字符上限
