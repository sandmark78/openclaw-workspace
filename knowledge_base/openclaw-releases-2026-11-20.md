## 🆕 重要新功能 (2026.10.33 - 2026.11.10)

### Agent 模板系统 (2026.11.10-beta.1)
- 直接从 ClawHub 包添加 Agent
- 单一 CLAW.md manifest + 捆绑技能文件夹
- 原生信任流检查

### OpenClaw ID (2026.11.10-beta.1)
- 通过 ID 隧道连接节点
- 从 Access 审批设备
- 将 owner 设备链接到个人身份

### 浏览器接管 (2026.11.10-beta.1)
- 从 Browser 面板直接接管 agent 的浏览器
- 无需停止 agent 即可手动操作

### 聊天控制增强 (2026.11.10-beta.1)
- 发送待处理的 steering 消息（不停止运行）
- 编辑排队消息
- 跨应用重启保留编辑器草稿

### 自动更新 (2026.11.10-beta.1)
- 配置自动更新时间表
- 传入版本运行自己的预更新演练

### 持久执行 (2026.11.10-beta.1)
- macOS 上 Gateway 重启后保持后台命令运行

### 长对话优化 (2026.10.33)
- 有界导出和恢复工作
- 减少聊天、记忆导出、Doctor 修复、Gateway 启动时的 OOM 失败

### 中断更新恢复 (2026.10.33)
- 执行器死亡时恢复中断的更新
- 版本偏差检查保护状态

### 回复持久化 (2026.10.33)
- 更多重启/重连路径下保留回复
- 恢复 Telegram 响应
- 避免丢失 WhatsApp 回复或跳过 Signal 消息

### 隐私增强 (2026.10.33)
- Side chat 对查看者保持私密
- 内部模型提示不显示在输出中
- 压缩时编辑摘要中的凭证

### 自动化增强 (2026.10.33)
- 对轮询条件和 MCP 事件做出反应
- 运行可重复脚本
- 使用明确允许的 MCP 服务器

### 技能搜索 (2026.10.33)
- 按需搜索和读取已安装技能
- 帮助 agent 找到相关指令而无需将所有技能放入提示

### 会话导入 (2026.10.33)
- 导入 Claude Code 或 Codex 转录
- 在本地和云环境之间迁移

### 其他改进
- 会话组织：暂停对话、选择自定义唤醒时间
- 会话上下文：在 Details 中显示任务进度
- 共享对话：表情符号反应
- 工作区放置：在配对设备上的现有文件夹中启动会话
- 首次运行设置：自动选择推理、提供可选记忆嵌入设置

## 🔧 重要修复

### 访问边界
- OpenClaw ID 成员权限一致应用于 HTTP 历史和连接应用面板

### 子 Agent
- 通过 Gateway 重启保留结果
- 请求者中断后重试完成交付

### OpenAI 响应
- 跨运行恢复项目冲突
- 延迟冲突恢复后完成重放安全回合

### Slack 交付
- 当原生流遇到边界或消息长度限制时保留最终回复

### Discord
- 编辑消息与新发送一致渲染
- 保留代码内的文字用户提及令牌

### Signal
- 保留引用消息中的原生提及接收者

### 聊天历史
- 当转录范围缩小时保留阅读位置
- 中断恢复后加载更早历史

### 响应性
- 减少冷会话压缩 CPU 和延迟回归
- 在 Gateway 线程外准备大历史
- 缩短大知识库扫描期间的写锁

## 📦 升级建议

### 风险评估
```
当前版本: 2026.7.1 (较旧)
目标版本: 2026.10.33 (extended-stable) 或 2026.11.10-beta.1

建议:
- 生产环境: 升级到 2026.10.33 (extended-stable/LTS)
- 测试环境: 可尝试 2026.11.10-beta.1
```

### 升级命令
```bash
# 升级到最新稳定版
npm update -g openclaw

# 或指定版本
npm install -g openclaw@2026.10.33

# 升级到 beta
npm install -g openclaw@2026.11.10-beta.1
```
