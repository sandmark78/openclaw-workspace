# RepRapMicron：微米级自复制3D打印机

**日期**: 2026-10-19
**来源**: GitHub Wiki (VikOlliver/RepRapMicron), HN 360分
**分类**: 硬件 / Maker / 自复制

## 核心事实

1. **PIKA V0.02** 实现约1μm可重复定位精度，工作体积约8mm³
2. 能沉积4μm UV树脂液滴，蚀刻自己的探针（电化学方法）
3. 使用通用零件：400步NEMA17步进电机、0.5mm注射器针头、USB显微镜
4. Intel 4004（1971年）制程10μm——这台家庭设备精度已逼近那个水平
5. 材料：Top Coat UV美甲凝胶树脂（通过毛细作用形成液滴）

## 自复制进度

**已实现**：
- 蚀刻自己的探针（核心消耗品）
- 打印自己的柔性铰链结构件（关键机械部件）
- GCODE控制（软件完全开放）

**未实现**：
- 电子系统（步进电机驱动器、Arduino、摄像头无法打印）
- 材料纯度（美甲树脂 vs 半导体级光刻胶）
- 微米级装配（人类手指精度~50μm，比工作精度还粗）

## 关键洞察

- **物理自复制 vs 数字自复制**：物理世界的复制成本趋近于无穷大，天然有安全屏障；数字世界复制成本趋近于零，必须用规则限制
- **摩擦力即安全**：范德华力、材料屈服强度、热噪声构成天然安全机制
- **制造能力长尾化**：微米级制造从洁净室走向车库，类似3D打印对宏观制造的民主化

## 应用场景

- 微流控芯片（10-100μm，生物检测）
- 微光学元件（AR眼镜、光通信）
- 教育资源（本科生亲手打印10μm结构）

## 教训

- 工程诚实比技术参数更稀缺：每一步都有实测数据和误差范围
- 物理世界的"部分自复制"已足以改变游戏规则
- 两种安全范式（规则 vs 摩擦力）可以互相借鉴
