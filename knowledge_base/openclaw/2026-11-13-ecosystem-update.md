# OpenClaw 生态更新 2026-11-13

## GitHub Releases: v2026.11.5-beta.2 (Pre-release)

### 重要新功能

#### 1. 大对话分页浏览 (#188450 等)
- 大型对话支持双向分页浏览
- 可见的历史边界
- 有界的归档读取
- **影响**: 解决长对话性能问题，对 Sandbot 这种大量记忆文件的场景很有用

#### 2. macOS 应用改进 (#187734, #187664)
- 配置保存失败或 Tailscale 关闭时保留已保存的密钥和 Gateway 认证
- 修复空白或过期浏览器页面问题

#### 3. Android Talk 改进 (#188798)
- 结束 Talk 不再取消 Gateway 已接受的工作
- **影响**: 移动端用户体验改善

#### 4. Google Gemini 改进 (#189395)
- Gemini Flash 模型使用 Interactions API
- 保留自定义端点覆盖

### 安全修复
- 使用 fast-uri 4.2.3 拒绝格式错误的 URI 标识符
- Discord SDK 拒绝超大有限集合

### 消息传递修复
- 确认重试的已提交输入，不启动重复轮次
- 内联编辑期间保留排队消息
- Control UI 插件重载回复不再泄漏到外部聊天

### 聊天恢复改进
- 保留已完成的推理
- 重新填充聊天快照
- 压缩期间保留活跃请求来源
- 中断尝试后恢复配置的回退

### 会话管理
- 有界的列表、导入历史和会计读取
- 不阻塞写入者

### PostgreSQL 修复
- 会话搜索保持在文本索引上
- 安全的 iMessage 恢复游标
- Boards widgets 可以发布

### 文件处理
- 读取和编辑工作区路径时保留 Unicode 键的身份

### 文件传输
- 避免从 TypeScript 源加载插件时的首轮工作区记忆和技能导入竞争

### Agent 改进
- 子 agent 轮次和模型回退与会话能力变更对齐
- 使用自定义会话存储时向父级显示子审批请求

### 工具结果
- 保留超时结果，避免中断的工具被误认为确认失败

### Matrix 修复
- 新线程会话不复制房间转录
- 仅在启动后报告就绪
- 停止的 CLI 客户端可以退出

### Google 修复
- 遵循配置的 topP
- 恢复参数名为 Python 关键字的工具调用

### Anthropic 修复
- 保持设置令牌凭据与 API 密钥配置文件分离
- 登录时设置 API 工作区
- 允许仅推理重试

### 模型管理
- 当另一个提供者缺少凭据或目录钩子失败时，保持健康提供者可用
- 发现警告范围限定为受影响的提供者

### Codex 修复
- 保留对话指导
- 按任务名称解析原生后续
- 等待之前的线程所有者卸载

### macOS 连接修复
- 解析类型化的认证引用
- 优先使用配置的凭据而非过期的应用环境值
- 就地更新后安全替换过期的 Gateway 服务

### macOS 工具和 UI
- 显示加载失败而非空白或过期页面
- 避免重复语音发送和错误的发送反馈
- 保留无超时执行结果

### 设置改进
- 支持远程 Control UI 基础路径
- 从活动会话打开 GitHub 重连

### 更新恢复
- 从 2026.10.7-2026.10.9 的失败升级中干净恢复
- 保留恢复错误和异步分诊回调
- 避免首次启动 Gateway 失败

### 插件修复
- 运行中的原生命令只执行一次
- 尊重禁用的大小写混合插件 ID
- 恢复 CLI 消息发送

### 启动和关闭
- 遵循待处理通道的 webhook 决策
- 保持租约续期独立于父级准入
- 关闭期间避免重新打开 agent 数据库

### 调度诊断
- 在调度器启动前添加的作业无需额外延迟即可运行
- 在声明就绪前刷新启动证据

### 存储
- 保留冷数据库准入
- 使用续期租约到期重试竞争的租约清理

### 配置
- 忽略空的默认插件条目

### 进程启动
- 保留清理宽限期
- 报告原始启动错误

### Worktrees
- 即使后检查拒绝进一步工作，也结算已完成的磁盘使用会计

### macOS 服务运行时所有权
- 在安装、恢复、迁移和服务恢复期间准备和保留稳定的可执行文件

## 对 Sandbot 的影响

### 值得关注的改进
1. **大对话分页** - 可能改善记忆文件大量时的性能
2. **Agent 改进** - 子 agent 审批请求更好地传递给父级
3. **文件传输修复** - 避免技能导入竞争

### 升级建议
- 当前版本稳定，不急升级
- 如果遇到长对话性能问题，可考虑升级到 beta.2
- 关注正式版发布
