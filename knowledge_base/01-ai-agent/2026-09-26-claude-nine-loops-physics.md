# Claude完成N=4超对称Yang-Mills九圈振幅计算

**日期**: 2026-09-26  
**来源**: Anthropic Research博客客座文章  
**核心实体**: Anthropic, Claude Science, Fable 5.1, N=4 SYM, 散射振幅

---

## 核心事件

物理学家Matt von Hippel于2026年8月7日发挑战：AI能否用学术级算力解决散射振幅领域的计算极限问题？

Anthropic的Liam Fitzpatrick和Siddharth Mishra-Sharma用Claude Science平台（Fable 5.1）在单提示词下完成N=4超对称Yang-Mills六粒子九圈振幅计算。

## 关键数据

- **计算成本**: $1,000-2,000（bootstrap方法仅~$100，相当于96 CPU × 7天）
- **人类此前极限**: 八圈（Lance Dixon, 2023年）
- **方法**: 已知bootstrap技术 + Python/SymPy，无新方法发明
- **验证**: Lance Dixon（SLAC教授）独立验证通过
- **并发**: 中国科学院何颂团队用GPT-6辅助也独立算出九圈symbol部分

## 核心洞察

1. **"低垂果实"认知盲区**: 人类对"困难"的判断混入了"什么值得做"的价值判断。96 CPU跑一周在人类看来"奢侈"，在AI看来"正常"
2. **无价值判断执行**: Claude没有"觉得奢侈"的概念，只是执行。提示词："我要去睡觉了，继续算"
3. **验证者态度**: Lance Dixon说"Claude理解我们2019和2023年的论文，除了合著者外比任何人都好"
4. **从"不可能"到"一两千美元"**: 一个月前还是人类算力极限，现在用$1000-2000就解决

## 教训

- AI的优势可能不在"更聪明"，而在"更耐心"——不会因价值判断而放弃暴力计算
- 学术界的计算极限可能比想象中低很多，因为研究者倾向于用数学技巧绕过而非投入算力
- 粒子物理散射振幅领域：大多数计算只到两圈，三圈已精英，五圈是历史最精确级别
