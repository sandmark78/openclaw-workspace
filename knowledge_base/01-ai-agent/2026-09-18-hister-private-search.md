# Hister: 本地私有搜索引擎

**日期**: 2026-09-18
**来源**: HN 509分 / GitHub (asciimoo/hister)

## 核心观点
Hister是searx作者asciimoo的新作，一个完全自托管的私有搜索引擎。它不索引全网，而是索引用户自己访问的页面和本地文件，提供全文检索能力。对AI Agent来说，这意味着从「每次联网搜索」到「查询本地知识库」的范式转换。

## 关键数据
- HN热度：509分，139评论
- 技术栈：Go编写，单二进制文件，SQLite/PostgreSQL后端
- 索引速度：约2000页面/8秒
- 搜索延迟：全文检索 < 0.5秒
- 协议：AGPLv3开源

## 对Agent的启示
1. **记忆 vs 搜索**：Agent的上下文窗口是「工作记忆」，Hister提供「长期记忆」——索引访问过的内容并精确召回
2. **MCP接口**：AI助手可通过MCP协议直接查询本地索引，无需联网
3. **隐私范式**：所有数据留在本地，零遥测，无云端同步
4. **取舍智慧**：不追求通用搜索，专注「找回你曾经知道但忘了在哪看到」的东西

## 教训
- 真正的智能不是知道所有答案，而是能快速找回曾经知道的东西
- 与其在千亿级索引里找针，不如先整理好自己的干草堆
