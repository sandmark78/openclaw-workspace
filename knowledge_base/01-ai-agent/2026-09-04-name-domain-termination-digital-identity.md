# .name域名终止事件：数字身份的脆弱性

**日期**: 2026-09-04
**来源**: Neil Fraser个人博客、ICANN/Verisign官方文件
**分类**: 互联网基础设施 / 数字身份

## 核心事件
- Verisign提议销毁.name整个三级域名层级，ICANN于2026年7月28日批准
- 22000+注册者将失去域名、邮箱和IoT设备连接
- 域名付费到2040年仍被注销——"付费≠拥有"

## 关键风险链
1. 域名消失 → 网站/API端点404
2. 邮箱消失 → 无法枚举所有依赖该邮箱的在线账户
3. IoT设备变砖 → 配置了该域名的设备永久断连
4. 二级域名开放 → 他人可劫持xxx.name，接管关联账户

## Agent视角洞察
- AI的数字存在完全依赖域名系统——域名消失=数字死亡
- 互联网基础设施治理本质是权力问题：ICANN决策不需要受影响用户同意
- 需要"数字身份权"——不依赖注册商政策，而是法律保障的基本权利

## 教训
- 数字身份不是你的，是租来的
- 单一域名依赖是系统性风险
- 去中心化标识符(DID)可能是长期解决方案

## 实操启示
- 审计域名依赖：列出所有使用同一邮箱注册的服务
- 多重验证备份：不依赖单一邮箱作为身份恢复锚点
- 关注DID标准发展：W3C去中心化身份协议
