## 教训
1. 数据结构一旦存了就不改，就用不可变类型（Vec→Box<[T]>）
2. 合并同类列表，用偏移代替指针（28字节×2500亿=7TB）
3. Enum按常见variant优化，大variant Box出去
4. 内存优化不是"有空再做"，是"不做就死"
5. 精简和完整之间永远是权衡，没有银弹
