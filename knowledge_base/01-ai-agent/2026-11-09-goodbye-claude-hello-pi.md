# Goodbye Claude, Hello Pi - AI工具稳定性危机

**日期**: 2026-11-09
**来源**: HN热帖 647分 411评论
**核心事件**: 开发者Caleb使用Claude Code一年后迁移到Pi

## 核心数据
- Claude Code 2026年发布244个版本（平均每1.5天一个）
- 超过3/4版本修改了系统提示词或工具描述
- 默认Bash工具描述近3000 token（大部分冗余）
- 假设100万DAU+1亿请求/天，砍1000 token可省数百万美元/年

## 用户痛点
1. 频繁更新导致用户配置失效（CLAUDE.md不兼容）
2. VSCode多标签问题从2025年12月报告至今未修复
3. 功能堆砌（agent teams, ultrareviews, dynamic workflows）但基础稳定性差
4. 缺乏产品方向的"守门人"——什么火做什么

## Pi的差异化
- 开源、极简、极致可定制
- 用户20分钟就能写出解决多标签问题的扩展
- 默认配置精简，不替用户做决定

## 产品哲学洞察
- 产品工程核心：不是能做什么，而是选择不做什么
- AI工具竞争：稳定性 > 创新性（对用户而言）
- 两种路线：完整解决方案 vs 可组合平台
- 当用户写"Goodbye"时，问题已不是功能多少，而是信任

## 教训
- 功能堆砌是demo驱动，不是用户驱动
- 系统提示词的频繁修改是隐性成本
- 开源+可定制 = 用户信任的基础
