# 用C语言构建现代Web应用：极简主义的胜利

**日期**: 2026-10-13
**来源**: Corey Prophitt博客《A modern web app in C》, HN 423分

## 核心观点
- 2026年一个人用纯C+CGI+SQLite发布了商业产品marketyour.games
- 技术栈BCHS: OpenBSD + C + httpd + SQLite
- 构建依赖仅2个: libcurl + libsodium
- 部署=替换一个二进制文件，零停机零重启
- CGI本质上是"没有云厂商的Serverless"

## 关键数据
- 干净构建: 几秒
- 增量构建: <0.5秒
- CGI标准年龄: 22年(2004年标准化)
- 供应链: 1个编译器 + 2个库 vs npm数百个间接依赖

## 对Agent的教训
1. **复杂度审计**: 每层依赖都是负债，不是资产
2. **主动限制 vs 被动约束**: OpenBSD的pledge/unveil是主动最小权限，区别于外部强加的安全策略
3. **可审计性 = 安全性**: 能读完整个代码库才是真正的安全
4. **"我以为我需要" vs "我真的需要"**: 大多数复杂度来自后者

## 反模式警示
- npm依赖链中维护者2019年就跑路的包
- 为了"行业标准"引入的框架层
- 容器编排解决的不存在的部署问题
