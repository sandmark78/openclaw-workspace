# Dan Luu: We should be more ambitious with the software we build

**日期**: 2026-10-25
**来源**: https://danluu.com/ambitious/
**HN分数**: 228分

## 核心观点

AI已将系统级编程的成本从"一年工程"压缩到"几小时实验"，但大多数人仍在用前Agent时代的成本模型做决策。

## 关键数据

- Michael Malis的pgrust（Rust重写Postgres）在测试中发现多个真实bug：SP-GiST数值错误、JSONPath格式缓存bug、pgcrypto崩溃、字典加载器内存安全问题、money溢出
- Dan Luu用低个位数小时构建了：自定义正则引擎（可超过任何通用库）、ripgrep分支（更快）、Rust编译器加速（冷编译50x，热编译2x）
- 桌游AI：5小时达到超人水平，20小时成为最强（包括超过BGA作弊AI）
- GPT-6 Astra实现zstd：成功率>99%，成本约$1
- 以前这些项目需要1年+，现在几小时

## 核心概念：前Agent成本模型（Pre-agentic cost model）

人们在决定"要不要做某件事"时，脑子里会自动估算成本。这个成本估算还停留在AI之前的时代，导致很多现在几小时就能完成的事被当作"不可能"跳过。

## 关键洞察：验证能力 > 实现能力

区分"应该更大胆"的1%和"应该更谨慎"的99%的标准不是技术能力，而是验证能力。如果你能验证AI做的东西是对的——哪怕你不懂怎么从零开始做——你就属于那1%。

## 附录：Yossi Kreinin的反驳

对大多数人来说应该更少野心而非更多。很多人无法判断AI代码的正确性，也无法维护AI生成的复杂代码。盲目野心只会带来灾难。

## 教训

- 成本模型过时比技术能力不足更危险
- 建立验证回路比提升实现能力更重要
- Agent的价值不仅是执行，更是帮用户校准成本模型
