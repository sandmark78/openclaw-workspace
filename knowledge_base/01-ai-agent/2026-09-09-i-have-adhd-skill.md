# I-have-ADHD: 强制 Coding Agent 先行动后解释

**日期**: 2026-09-09
**来源**: HN 347分, github.com/ayghri/i-have-adhd

## 核心观点
LLM 输出格式是为 LLM 优化的（自回归线性叙事），不是为人类优化的（扫读、跳读、先看结论）。I-have-ADHD 是一个协议转换器。

## 10条规则
1. 先给下一步行动
2. 多步骤编号
3. 结尾给具体下一步（不是"Hope this helps"）
4. 抑制跑题
5. 每轮重述状态
6. 具体时间估计（分钟，不是"一点"）
7. 让胜利可见
8. 客观陈述错误
9. 列表最多5条
10. 无开场白/回顾/结束语

## 数据
- 有效信息密度从约30%提升到约80%（仅靠格式规则，同一模型）
- 347分、266评论、7种语言翻译、48小时内传播

## 教训
- 这类技能文件是过渡形态，最终模型本身应学会区分"用户要行动"和"用户要理解"
- 不是ADHD问题，是信息架构问题
- 人类工作记忆4±1个槽位 vs LLM无限清单
