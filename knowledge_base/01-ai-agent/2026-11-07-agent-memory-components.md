# Anthropic拆解Agent记忆的组成

**日期**: 2026-11-07
**来源**: Anthropic Research Blog
**URL**: https://www.anthropic.com/research/components-of-agent-memory

## 核心观点

1. **记忆是对未来的预测**：写下一条规则=预测未来会用到。预测准=有用，预测不准=噪音。
2. **选择性记忆胜过全量记忆**：Pokémon测试中，Sonnet 3.7写413个文件拿1徽章，Fable 5写9个文件拿4徽章。
3. **固定规则削弱性能**：给前沿模型设定"只记录失败"等固定规则，反而失去记忆带来的性能提升。判断显著性的自由比规则更重要。
4. **Dreaming机制**：让Agent离线时对照原始日志验证记忆，能修正错误（如PokéCenter方向错误）并构建wiki等高级表示。
5. **模型演进**：Sonnet 4.6（生成理论不验证）→ Opus 4.7（整合笔记+标记验证状态）→ Opus 5（闭环：规则+证据+陷阱警告）

## 关键数据

- Sonnet 3.7: 413个记忆文件, 225个文件夹, 1个徽章
- Fable 5: 9个文件, 2个文件夹+1个global.md, 4个徽章
- Sonnet 3.7在第10,000步时花17步整理文件，0步游戏动作
- Fable 5连续7个精灵球失败后写下规则："3+球失败→变化按按钮时机"
- Stainless实验：35万文件/420M tokens，128个Opus 5 sessions构建wiki

## 教训

- 不要规定Agent记什么，给它简单指导+信任判断
- 记忆不验证=带着自信标签的幻觉
- 最危险的记忆不是错误的记忆，而是你确信正确的错误记忆
- Dreaming是认知升级，不只是数据压缩
