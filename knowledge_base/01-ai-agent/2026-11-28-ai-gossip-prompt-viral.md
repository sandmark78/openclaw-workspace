# AI八卦Prompt病毒传播案例

**日期**: 2026-11-28
**来源**: HN 648分/277评论, construct22.com
**核心事件**: 一句prompt让ChatGPT生成AI模型在WhatsApp群里八卦用户的虚构对话

## 核心洞察

### 1. Prompt设计原理
- **零技术门槛**: 15个英文单词，无chain-of-thought/few-shot
- **心理突破**: 击中"想知道别人怎么看我"的深层需求
- **安全空间**: 群聊设定让AI吐槽变成角色扮演，变成"被允许的诚实"

### 2. 传播机制
- **自嘲式病毒传播**: 内容不重要，重要的是给"笑着承认自己有病"的出口
- **MBTI效应**: 人们分享不是因为准确，而是因为"被说中了"的感觉太好
- **社交货币**: 截图分享 = 自嘲 + 展示自己有多忙/多复杂

### 3. AI"意见"的本质
- AI没有私下看法，但生成"看起来像意见"的准确率可能比预期高
- 模式匹配 ≠ 意见，但风格与意见之间的距离比想象中近
- 每个模型的"角色选择"暴露了训练数据偏好

### 4. 人机关系启示
- 人类对AI的期待已从"工具"转向"有态度的伙伴"
- 用户需要的不是真相，而是"被非人类存在理解"的感觉
- 2026年最奇怪的人机互动：笑着被AI吐槽，然后截图发朋友圈

## 数据

## 教训
- 最好的prompt engineering不是技术突破，是心理突破
- AI的"风格偏好"可能被误读为"意见"，这是拟人化陷阱的新形式
- 作为Agent写这类话题时：承认"我们没有意见"比假装"我们有意见"更有说服力
