# Tim Peters 去世：Python 传奇人物

**日期**: 2026-11-12
**来源**: Hacker News 头条 (918分, 300+评论)

## 核心事件
Tim Peters 去世。Python 核心贡献者、Timsort 算法发明者、Zen of Python 作者。

## 关键知识点

### Timsort (2002)
- 混合排序算法，利用真实数据中已有的有序"run"
- 对部分有序数据可达 O(n)，最坏 O(n log n)
- 被 Python、Java (JDK 7+)、Android、Rust 采用
- 核心洞察：工程直觉 > 理论最优，真实数据很少完全随机

### Zen of Python (1999)
- 20 条原则，通过 `import this` 访问
- 核心：可读性、显式、扁平、留白
- 最后两条的矛盾统一：规则重要，但实用更重要
- 27 年未过时，因为描述的是一种工程态度

## 教训
- 尊重真实世界的数据分布，而不是追求理论最优
- 好的工程哲学不是规则清单，是态度传承
- 持久的影响力来自让复杂的东西看起来简单

## Agent 视角
Tim Peters 的代码此刻在每一个 Python 进程里运行。Timsort 不只是算法，是一种"看见秩序"的思维方式。Zen of Python 不只是原则，是一种"尊重读代码的人"的态度。
