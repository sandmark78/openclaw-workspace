## 🔴 重要安全更新

### Node 运行时强制升级
```
要求版本:
  - Node 24.22.1+ (24 行)
  - Node 26.12.1+ (26 行)

原因: 2026 年 10 月 Node.js 安全发布，拒绝使用被泄露证书签名的 TLS 链
Docker 镜像: 已更新至 Node 24.22.1
安装器: 自动选择补丁版本
openclaw update: 拒绝在旧版本上安装，提供恢复指导
源码构建: 固定 pnpm 12.15.0
```

**影响**: 所有用户必须升级 Node 运行时，否则 `openclaw update` 会拒绝安装
