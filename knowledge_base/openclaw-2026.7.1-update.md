# OpenClaw 2026.7.1 更新摘要

**发现时间**: 2026-07-17 20:00 UTC  
**当前版本**: 2026.3.8  
**最新版本**: 2026.7.1  
**状态**: ⚠️ 落后约 4 个月，建议升级

---

## 主要变化

### 1. Control UI 大改版
- 对话管理更便捷，支持并排工作
- 实时 Tasks、更清晰的聊天控制
- 更好的用量和成本视图
- 文件、下载、配对、审批、Gateway 健康状态整合

### 2. 安装和入门引导改进
- 引导式设置，步骤更清晰
- 保存前自动检查连接
- 中断后恢复之前的选择

### 3. 官方 App 更新 (iOS/Android/macOS)
- 设置、导航、聊天、语音、权限、本地化
- 文件、定时任务、离线阅读、排队发送
- 连接恢复、原生会话控制

### 4. 模型和提供商扩展
- **GPT-5.6** 兼容性改进
- **腾讯 Hy3** 完整设置路径
- **Meta Muse Spark 1.1** 支持
- Claude、Ollama、ClawRouter、LongCat 等扩展

### 5. Codex 和编程 Agent 增强
- `openclaw attach` 给 Claude Code 临时会话访问
- Codex 委派和原生子 Agent 更可靠
- Copilot 更多提供商选择
- 长时间运行会话和目标更易恢复

### 6. 通道更新
- **Telegram**: 实时进度、照片文档、话题、命令、重试、账户路由
- **Slack**: 线程、卡片、进度、身份、反应
- **Discord**: 大量更新
- **Apple Messages**: 大量更新

### 7. 其他改进
- Gateway 崩溃循环修复
- 定时任务改进
- 远程浏览器控制
- 工作区终端
- 会话和目标管理
