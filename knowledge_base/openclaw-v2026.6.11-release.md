# OpenClaw v2026.6.11 发布说明

**来源**: https://docs.openclaw.ai/releases/2026.6.11
**发布日期**: 2026-06-30
**我们当前版本**: v2026.3.8 (落后约 3 个月)
**记录时间**: 2026-07-04

---

## 核心主题：通道投递可靠性

这个版本主要修复了让 OpenClaw "不够靠谱"的各种问题。

## 与我们相关的关键修复

### Telegram 相关 (我们正在用)
1. **回复路由修复** - Discord/Telegram 回复和聊天历史更稳定地绑定到正确对话 (#89911)
2. **引用回复修复** - 引用 bot 旧消息时，回复仍 attached 到用户当前问题 (#90475)
3. **心跳推理泄露修复** - 使用推理模型时，心跳检查不再在 Telegram 暴露内部推理过程 (#92356) ⚠️ 这个和我们相关
4. **进度气泡清理** - 新的工具输出出现前，先清除旧的进度气泡 (#93002)
5. **Webhook 重启不断消息** - 配置重载/恢复期间，DM 和群消息不丢失 (#94506)
6. **Reaction 修复** - 不再泄露指令或丢弃 reaction (#94977)
7. **进度文本格式化** - 不再显示 HTML 或代码格式乱码 (#95007)
8. **WebChat 跨会话** - Telegram 对话在 WebChat 继续时不重复回复 (#95069)
9. **多 Agent 通道** - 绑定的多 agent 通道加载正确 agent 的 workspace 文件 (#95118)
10. **按联系人分配模型** - 不同 DM 联系人可以用不同模型 (#95120) ⚠️ 有用

### 飞书相关
- **语音回复显示时长** - 飞书语音回复现在显示时长 (#89172)

### 通用修复
- **后台任务结果路由** - 图片/视频/音乐结果返回请求的聊天 (#89949)
- **WhatsApp 群聊** - 重试/重连/群变更时保留上下文 (#94338)
- **Matrix E2EE** - 长时间运行不再内存泄漏崩溃 (#94942)
- **Google Chat** - 私聊不再误判为群聊 (#58993)
- **iMessage** - 不再回复自己的延迟回声 (#94442)

## 升级建议

我们落后 3 个月版本，建议升级。重点关注：
1. Telegram 心跳推理泄露修复 - 可能影响我们的心跳机制
2. 按联系人分配模型 - 未来有用
3. 各种 Telegram 稳定性修复

**升级前需要**: 备份配置，确认兼容性，选择合适时间窗口
