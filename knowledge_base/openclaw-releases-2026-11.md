# OpenClaw 版本更新记录 (2026-11)

**发现时间**: 2026-11-19 20:00 UTC
**当前版本**: 2026.7.1
**最新版本**: 2026.11.10-beta.1 (预发布) / 2026.11.6 (稳定)
**状态**: ⚠️ 落后约 4 个月，建议升级

---

## 2026.11.10-beta.1 (预发布)

### 重大新功能

1. **Agent 模板 (Agent Templates)**
   - 直接从 ClawHub 包添加 Agent
   - 单一 CLAW.md manifest + 捆绑技能文件夹
   - 原生信任流检查
   - PR: #195707, #196322, #196348

2. **OpenClaw ID**
   - 通过 ID 隧道连接节点
   - 从 Access 面板审批节点
   - 将设备链接到个人身份
   - PR: #193982, #194007, #197628

3. **浏览器接管 (Browser Handoff)**
   - 从 Browser 面板直接接管 agent 的浏览器
   - 无需停止 agent 运行
   - PR: #197928

4. **聊天控制增强**
   - 发送待处理的转向消息（不中断运行）
   - 编辑排队消息
   - 跨应用重启保留编辑器草稿
   - PR: #193665, #197846, #197908

5. **自动更新调度**
   - 配置自动更新时间表
   - 新版本运行自己的预更新排练
   - PR: #193713, #197922

6. **持久执行 (Durable Execution)**
   - macOS 上后台命令在 Gateway 重启后继续运行
   - PR: #197474

7. **工具发现优化**
   - 可选的使用频率排序工具索引
   - 支持 MCP 工具
   - PR: #197128, #198348

8. **知识搜索改进**
   - 使用过时版本措辞时也能找到当前记录
   - PR: #193742

9. **语音和图像**
   - 在设置→对话中选择语音转文字模型
   - Agent 可在交付前审查生成的图像
   - PR: #197906, #198227

10. **状态升级**
    - 启动时使用复制交换迁移 Gateway 状态
    - 不再修改活动存储
    - PR: #198389

### 其他改进
- Access: 添加访客成员角色（沙箱化会话工具）
- Providers: 支持 Parallel Decisions（原生 + OpenRouter）
- Backups: 长时间备份显示阶段和字节进度

### 重要修复
- Subagent 结果在 Gateway 重启后保留
- Slack/Discord/Signal 消息传递修复
- 聊天历史读取位置保留
- 冷会话压缩 CPU 和延迟优化
- 大历史记录在 Gateway 线程外准备

---

## 2026.11.6 (稳定版)

### 重点改进

1. **更流畅的升级**
   - 桥接 2026.11.5 更新器到当前发布路径
   - Windows 上正确验证暂存插件依赖

2. **更弹性的对话**
   - 配置编辑时保持子 agent 和后台运行
   - Gateway 重启中断发送时交付最终答案

3. **更轻量、响应更快的 Gateway**
   - 减少启动内存压力和受限主机上的常驻内存
   - 延迟未使用的本地凭证运行时
   - 插件工具发现不阻塞 Gateway

4. **可靠的长时间模型回合**
   - 保留仅追加的提供商历史
   - 精确的 Responses 工具参数字节
   - 长时间、工具密集的 Claude CLI 回合的最终回复

5. **更好的对话连续性**
   - 压缩期间保持已加载的聊天历史可见
   - iOS Talk 回合可继续超过之前的 30 秒截止

### 其他改进
- ChatGPT 设置和模型更新
- 大文件读取优化（请求文本页后停止扫描）
- 凭证处理改进（内联环境凭证编辑）
- 安全配置写入（保留格式错误的 UTF-8 源）
- PostgreSQL 升级改进
- 会话存储优化（大回退不耗尽共享数据库工作器）
- 自动化连续性（聊天标识符更改时保持运行）

## 升级建议

### 当前状态
- 我们的版本: 2026.7.1 (2026年7月)
- 最新稳定: 2026.11.6 (2026年11月)
- 差距: 约 4 个月

### 升级收益
1. **Agent 模板** - 可直接从 ClawHub 安装 Agent，对我们发布技能有用
2. **浏览器接管** - 调试时可以直接接管 agent 浏览器
3. **持久执行** - 后台命令在重启后继续（虽然我们是 Linux，不是 macOS）
4. **性能优化** - 内存占用降低，响应更快
5. **Subagent 稳定性** - 结果在重启后保留

### 升级风险
1. 配置可能需要迁移
2. 插件兼容性需要验证
3. 需要测试 Telegram 通道是否正常

### 建议
- 先等 2026.11.10 稳定版发布
- 或在测试环境先试 beta 版
- 升级前备份 workspace 和 openclaw.json
