## 🎉 Highlights

### 1. 恢复兼容的失败更新
保留上一个安装包，当 schema 和配置检查证明回滚安全时，用之前的配置和服务恢复；数据库迁移仍需验证过的更新前备份。(#140339)

### 2. 插件统一管理
在 Control UI 中一站式发现、安装、管理 ClawHub 插件，统一插件工作区。(#135839 等多项 PR)

### 3. 预置云会话
从本地项目或公共 GitHub 仓库启动符合条件的 Linux 会话，可在 Control UI 中从对话前构建可复用快照。(#143227 等多项 PR)

### 4. 终端内问答
在连接网关和本地 TUI 会话中，支持键盘驱动的选择、自由文本答案和多问题提示。(#143273)

### 5. GPT Image 2.5
可为图像生成/编辑选择新的 Flare 和 Sunburst 变体（通过 OpenAI 或 fal），无需更改默认模型。(#143007)
