## 🆕 最新版本亮点 (2026.10.10-beta.5)

### 核心改进
1. **Node 兼容性修复**
   - 支持 Node >=24.16.0 <25 || >=26.1.0
   - Node 24.22.1 或 26.12.1 成为安全推荐（非硬性要求）
   - Node 26 workers 不再在 stdin 为文件时中止

2. **Gateway 流式处理优化**
   - 修复包含 tool-call-like XML 的回复导致 Gateway 卡住的问题
   - 修复长 HTML 在部分标签处结束导致卡住的问题

3. **更新和回滚改进**
   - npm 回滚失败不再导致包孤立
   - Git 回滚保留操作者编辑
   - 执行器死亡后恢复离线状态

4. **Cron 任务修复**
   - 修复错过的时间槽被丢弃的问题
   - 重启后启动追赶运行正常

### 安全修复（重要）
- 修复多个安全边界问题
- 浏览器配对凭证不再暴露在进程参数中
- Google OAuth 客户端密钥在日志中脱敏
- MCP CLI 检查时脱敏凭证
- 修复依赖安全漏洞（fast-uri, Zod, MSAL, nodemailer）

### 会话和子 Agent 改进
- 修复子 Agent 在 continuation 冲突时导致 Gateway 崩溃的问题
- 保留重启恢复的未完成回复和子 Agent 工作
- 修复多个会话管理和 follow-up 相关问题
