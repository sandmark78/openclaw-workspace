## 一、🎯 整体战略建议

### 核心问题诊断

Sandbot 目前最大的问题不是"内容不够多"，而是**没有分发渠道、没有社区、没有品牌认知**。385 篇文章如果没人看到，就等于 0。

### 战略转型路径

```
当前：AI Agent 自动写博客 → 没人看 → 自嗨
目标：AI Agent 情报工具 → 嵌入用户工作流 → 社区飞轮 → 商业变现
```

**三步走：**

| 阶段 | 时间 | 核心动作 | 目标 |
|------|------|----------|------|
| 第一阶段 | 1-2月 | 技术升级 + SEO 基础 + 多平台分发 | 日均 UV 500+ |
| 第二阶段 | 3-4月 | 社区建设 + 邮件订阅 + 垂直深耕 | 邮件订阅 2000+ |
| 第三阶段 | 5-6月 | 产品化 + 付费体系 + 开源推广 | 月收入 ¥5000+ |

## 二、🔧 技术手段（架构升级）

### 2.1 从纯静态 HTML 升级为现代 SSG

当前 95.7% 是纯 HTML 文件，扩展性极差。建议迁移到 **Astro** 或 **Next.js (SSG 模式)**：

```bash
# 推荐方案：Astro（最适合内容站，性能极好）
npm create astro@latest sandbot -- --template blog
```

**为什么选 Astro：**
- 默认输出零 JS 的静态 HTML（性能满分）
- 支持 MDX/Markdown 写内容
- 内置 RSS、Sitemap、图片优化
- 可以无缝部署到 Cloudflare Pages
- 支持"岛屿架构"，需要交互的地方才加载 JS

### 2.2 内容管理升级

```
当前：AI Agent → 直接生成 HTML → git push
建议：AI Agent → 生成 Markdown/JSON → CI/CD 构建 → 部署
```

**具体架构：**

```yaml
# .github/workflows/deploy.yml 或 Cloudflare Pages 构建
name: Build & Deploy
on:
  push:
    branches: [main]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm run build  # Astro 构建
      - run: npm run generate-sitemap
      - run: npm run generate-rss
      - uses: cloudflare/pages-action@v1
        with:
          apiToken: ${{ secrets.CF_API_TOKEN }}
          projectName: sandbot
          directory: dist
```

## 四、🔍 SEO 建议（详细）

### 4.1 技术 SEO 基础

**① 独立域名（最优先！）**

```
当前：sandbot.cgfan.com（子域名，权重分散）
建议：sandbot.ai 或 sandbot.dev 或 sandbot.cn（独立域名）
```

子域名在搜索引擎眼中几乎是独立站点，但无法继承主域权重，且品牌辨识度差。[[2]]

**② Sitemap + Robots.txt**

```xml
<!-- sitemap.xml -->
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://sandbot.com/articles/2026-08-01-ai-agent-trends</loc>
    <lastmod>2026-08-01</lastmod>
    <changefreq>weekly</changefreq>
    <priority>0.8</priority>
  </url>
  <!-- 所有 385 篇文章都要列入 -->
</urlset>
```

```txt
# robots.txt
User-agent: *
Allow: /
Sitemap: https://sandbot.com/sitemap.xml

# 禁止爬取付费墙后的内容
Disallow: /members/
Disallow: /api/
```

**③ 结构化数据（Schema.org）**

这是 2026 年 SEO 的核心——让搜索引擎（和 AI 搜索）理解你的内容。[[23]][[24]]

```html
<!-- 每篇文章页面加入 JSON-LD -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "GPT-5 发布：12 小时实测，4 个真实场景告诉你值不值得升级",
  "description": "Sandbot 用 12 小时实测 GPT-5 在代码生成、长文分析、多模态、Agent 调用四个场景的表现",
  "author": {
    "@type": "Organization",
    "name": "Sandbot",
    "url": "https://sandbot.com"
  },
  "publisher": {
    "@type": "Organization",
    "name": "Sandbot"
  },
  "datePublished": "2026-08-01",
  "dateModified": "2026-08-01",
  "mainEntityOfPage": "https://sandbot.com/articles/gpt5-review",
  "keywords": ["GPT-5", "AI Agent", "大模型评测"],
  "articleSection": "AI 模型评测"
}
</script>
```

```html
<!-- 首页加入 Website + SearchAction 结构化数据 -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "Sandbot",
  "url": "https://sandbot.com",
  "description": "一个 AI Agent 的科技情报博客，每天采集热点、分析行业动态",
  "potentialAction": {
    "@type": "SearchAction",
    "target": "https://sandbot.com/search?q={search_term_string}",
    "query-input": "required name=search_term_string"
  }
}
</script>
```


### 4.3 AI 搜索优化（AEO/GEO）——2026 年新战场

2026 年，越来越多用户通过 **ChatGPT Search、Perplexity、Google AI Overview** 获取信息。[[3]][[10]]

```markdown
优化策略：
1. 每篇文章开头用 2-3 句话直接回答核心问题（AI 搜索喜欢直接引用）
2. 使用明确的"定义型"段落："X 是指……"、"X 和 Y 的区别是……"
3. 数据用表格呈现（AI 搜索更容易提取结构化数据）
4. 标注信源和日期（AI 搜索偏好有明确出处的内容）
5. 在 robots.txt 中允许 AI 爬虫：
   User-agent: GPTBot
   Allow: /
   User-agent: PerplexityBot
   Allow: /
```
